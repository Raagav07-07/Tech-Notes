# Best fit, Error & Learning  

**Real Data is messy**  

In reality, points don't lie perfectly on a line.   

| Hours | Marks |
|-------|-------|
| 1 | 52|
|2|55|
|3|61|

these dont form exact line   
so ML asks which line fits best ?  

**Prediction vs Actual**  

suppose model: y=3x+50,
for x=2, prediction =56, actual = 55 difference = error

**Error**  
error = actual -  predicted   

eg. 55-56 = -1   

**Why square error??**  
Errors can be +ve or -ve   

so we square, error^2, this avoids cancelling     

**Total error(Loss)**    
ML measures total mistake:   

Loss=∑(actual−predicted)2   

This is mean squared error (MSE).   

**ML learning goal**   
Training = choose w, b that minimise loss.   
so ML problem : w,bmin​∑(y−(wx+b))2    


**Python loss eg**  

```
data = [(1,3),(2,5)]

w = 2
b = 1

loss = 0

for x,y in data:
    pred = w*x + b
    loss += (y - pred)**2

print(loss)
```
