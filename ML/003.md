# Vectors, Matrix 

*Numpy* - is the foundation of the multi dimensional array operations for the data  

we can create an array or matix using `np.array()` or `np.mat()` (not recommended). for g. np.array([[1,2],[2,3]]).

**Sparse matrix** (CSR) - used to compress the sparse matrix(matri with zero elements greater)  `from scipy import sparse - sparse.csr_matrix(np.array())`

Numpy uses indeing but in different way - 1D vector[1], 2D vector[1,2] 

**shape** - used to view the no of rows and cols of the matrix eg.mat.shape o/p: (r,c)   

**size** - view no of elements in matrix  

**ndim** - view dimension of the matrix   

**Operations** - to create a vectorise function...

```
add_100= lambda i:i+100
vectorize_add=np.vectorize(add_100)
vectorize_add(mat)
print(mat)
```

**Broadcasting** - Allowing operations between arrays even if their dimensions are not the same


**to find max and min** - we use np.max(mat,axis=0) and np.min(mat,axis=1), axis=0 for col , axis=1 for row  

**Average, variance, Standard deviations** 

np.mean(), np.var(), np.std()   

np.mean(mat,axis=0) -> finding mean value in each column   

**reshape()** - changes the shape(no of rows and columns) of an array without changing the values. reshape(1,-1) -> -1 incidactes "as manhy columns needed", reshape(12)->1 row and 12 values

**Transposing a vector** - to transpose a vector we use (.T) for eg: mat.T   

**flatten()** - flattening a matrix to single dimension   

**Finding a rank of a matrix - number of linearly independent row or columns** - np.linalg.matrix_rank(mat)

**To find determinant** - np.linalg.det(mat)   

**To get diagonal of a matrix** - mat.diagonal(offset=1) -> return diagonal one above the main diagonal offset=-1 ->one below main diagonal  

**Trace of a matrix** - sum of main diagonal sum(matrix.diagonal()) or matrix.trace()

**Finding eigen values and eigen vectors** - 

`eigenvalues,eigenvectors=np.linalg.eig(matrix)`  

** dot product** - np.dot(vector_a,vector_b)  

**Inverse of a matrix** - np.linalg.inv(matrix)   

**Generating random values**  -  np.random.seed(0) -> np.random.random(3)
