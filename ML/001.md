# Basic math for ML  

**Lines, Slopes & Predictions**  
**Line** - Shows relationship between two variables eg. Hours studies -> marks, height->weight.   
If one increases, other increases -> line   

**Equation of a line**  
General form : y = mx+b   
where, m= slope, b= intercept  

**Slope**  

Slope = how steep line is,   
m= change in y/change in x    

for eg. (1,2) and (3,6) , m=(6-2)/(3-1)=4/2=2.. so if x increases one time y increases 2 times   

**Intercept(b)**  
when line crosses y-axis, if x=0: y=b  

**How it relates to ML**   
Linear regression model : y=wx+b,   
where slope -> weight w, intercept -> bias b    

ML training = finding best w and b.   

Eg. y=2x+1,if x=5 then y=11 thats ML prediction.     

**Real World eg**  
Eg. hors studied -> marks  
Model learns : marks = 5 x hours + 20,
if student studies 6 hrs marks = 50  thats regression.
