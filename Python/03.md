**Iterable**  
An iterable is a python object that python can loop.  
Internally, it implements the iterator protocol:
* __iter__()
* __next__()

You don’t see this, but **for** uses it.

**How a for really works?**  
```
for x in [1, 2, 3]:
    print(x)
```

Internally,  
```
it = iter([1,2,3])
while True:
    try:
        x = next(it)
        print(x)
    except StopIteration:
        break
```

**Looping over different structures**  

**List/tuples/string/**  
for item in lst:

**Dict**  
```
for k in d:          # keys
for v in d.values(): # values
for k,v in d.items():# both
```  

**range**: It generates numbers on demand → memory efficient. Eg.range(5)  

**enumerate()** - gives both index and value of a list. `for in,val in enumerate(lst)`  

**zip()** - for parallel iteration `for n,s in zip(names,size)`. If one contains more values than other than it will get skipped.  

**List Comprehension**  
`evens = [x for x in range(10) if x % 2 == 0]`  

**Dictionary Comprehension**  
`d = {x: x*x for x in range(5)}`  

**Membership is faster in dict and sets since they are hashed.**   
`if x in s:   # O(1)`
