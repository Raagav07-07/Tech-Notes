# Functions, scope and Stack frame  

**Functions**  
Functions is an object stored in memory with a name pointing to it in python.  
Eg. `def greet(name:str):` 

Conceptually, greet -> object stored in heap memory.   
We can even do x=greet.   

**What happens when you call a function?**  
Stack frame is created which contains the local variables, arguments, return address. Ater rerturn -> the stack frame is destroyed.   

*Python resolved variables in the specified order*,
- Local
- Enclosing
- Global
- Built-in   

**Local vs Global variable**  
```
x=5
def add(i):
    x=10 //local
```  

if we want global variable then specify **global** keyboard   

**Default values**  
```
def add(item, lst=[]):
    lst.append(item)
    return lst
```  
here the default arguments are evaluated once not at every call.  

***args** -> multiple positional arguments, def sum(*num).   
***kwargs*** -> multiple key value arguments(dict)   

**Function as Arguments**  
```
def ret(func,val): 
    return func(val)
```
