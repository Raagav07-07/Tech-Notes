# Memory Model  

*Python is object-reference based*  

**Python variables does not store values, it stores reference to the object. Everything in python is object**  

In python,   
- Numbers, strings, lists, functions, classes all are objects stored in a memory(heap).
- Variable nams live in a namespace and holde reference to those objects.

Think "name"->object in memory , name!=value stored in it  

**Namespaces and references**  
When we write a=10, what happens conceptually is Nmaespace(your scope) where a-> int object(10) in memory(heap).  
Now b=a , b and a points to same object  

**Immutable vs Mutable**  
Immutable object, cannot be changed after creation.  **int, float, str, tuple**  
eg. 
```
x="hello"
y=x
y=y.upper()
```

""hello" is an object, y.upper() creates a new string objevt "hello", x points to same old object.  

**Mutable object**   
Can be modified without creating new object  
for eg, 
```
a=[1,2,3]
b=a
b.append(4)
```

one list objwct exists, both a and b refer to it, Mutation affect the same object.  

**Identity vs equality**   

**Identity**(is) -> checks if same object  
**Equality**(==) -> Checks if same values exists  

**Function arguments = Passing references**   
Python does not pass by value or reference like c++.  
It passes object reference by assignment.  

**Memory areas**  
- **stack** -> Function calls, variable names (ref)
- **Heap** -> object they point to

**Garbage collection**  
Python removes the garbages automatically.
